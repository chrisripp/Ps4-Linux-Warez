PS4-TOOLS Compiler Mesa

Télécharger les patchs et scripts nécéssaire

wget "http://hostps4.free.fr/Ps4-Linux-Warez/scripts/libdrm-26.patch 
wget "http://hostps4.free.fr/Ps4-Linux-Warez/scripts/mesa-26-triki1-OH-v2.diff 
wget "http://hostps4.free.fr/Ps4-Linux-Warez/scripts/mesa-installdir-merge.sh 
wget "http://hostps4.free.fr/Ps4-Linux-Warez/scripts/ps4-tools-en-final7.sh

Nous allons utiliser mesa-build.py, utiliser PS4TOOLS pour le télécharger,

Placer mesa-build.py a la racine de votre /home.

Lancer ./mesa-build.py dans votre terminal.

Nous allons le compiler a blanc, un première fois, c'est a dire sans patch PS4.

La compilation terminée, et réussie, nous plaçons les patch libdrm et mesa dans les dossiers correspondants

Libdrm-git et mesa-git

Nous allons utiliser ces commandes pour patcher nos dossiers:

Dans le dossier libdrm-git: Nous testons le patch avec cette commande

patch -p1 --dry-run < libdrm-26.patch

Si tout est passé on patch, comme ceci:

patch -p1 < libdrm-26.patch

Dans le dossier mesa-git: Nous testons le patch avec cette commande

patch -p1 --dry-run < mesa-26-triki1-OH-v2.diff

Si tout est passé on patch, comme ceci:

patch -p1 < mesa-26-triki1-OH-v2.diff

Nous allons maintenant utiliser le script mesa-installdir-merge.sh

Coller ce script dans mesa-git/installdir/, puis lancer le en root

Un dossier output va être crée, copier les dossiers mesa-git/installdir/ouput/etc et usr,

A la racine de votre système / en utilisateur root

Lancer heaven, si vous n'avez pas de pixels, votre mesa est bien patché et installé

Ne supprimer jamais libdrm-git et mesa-git, et pensez a faire une sauvegarde avec vos patch, et votre mesa-build.py
