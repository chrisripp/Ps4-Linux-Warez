Initramfs PS4 Linux

Les images initramfs prêtes à l'emploi pour chaque distribution, générées pour le noyau KHEOPS-FullLTO (Liverpool/Gladius, GFX7).

ramfs
zcat /boot/initramfs-ps4.img | cpio -t | head

À quoi sert l'initramfs sur PS4 Linux ?

2 commentaires

L'initramfs est le système de fichiers minimal chargé en RAM au démarrage, avant le montage de la partition racine. Sur PS4 Linux, il embarque les modules nécessaires au démarrage sur le matériel Liverpool/Gladius : contrôleur SATA/NVMe, southbridge Baikal, et les premiers modules DRM/amdgpu pour la bascule vers le pilote graphique. Chaque image est générée spécifiquement pour le noyau KHEOPS-FullLTO correspondant à la distribution.

Les images ci-dessous sont construites avec dracut (ou mkinitramfs selon la distribution) à partir des modules du noyau KHEOPS-FullLTO, compilé en Clang/LLVM Full LTO pour Jaguar (-march=btver2 -mtune=btver2). Elles intègrent le support Baikal (PCI IDs, MSI, offsets mémoire portés du kernel 5.4 vers 6.15.4) ainsi que les premiers correctifs GFX7 pour Liverpool/Gladius.

Les liens et empreintes SHA256 sont à compléter une fois les fichiers hébergés sur l'espace free.fr (dossier /dl/initramfs/ par exemple).

Reconstruire l'image soi-même

# sur Debian Trixie
sudo apt install dracut
sudo dracut --force --kver 6.15.4-kheops-fullto /boot/initramfs-trixie-ps4.img
