Le noyau KHEOPS-FullLTO

2 commentaires

Le bzImage est le noyau Linux compressé qui démarre la machine. Sur PS4 Linux, chaque bzImage est construit avec Clang/LLVM en Full LTO, ciblé sur l'architecture Jaguar (-march=btver2 -mtune=btver2), avec le support Baikal (southbridge) porté du kernel 5.4 vers 6.15.4 et les registres GFX7 définis dans gfx_v7_0.c : LIVERPOOL_GB_ADDR_CONFIG_GOLDEN (0x12010003) pour la PS4 standard et GLADIUS_GB_ADDR_CONFIG_GOLDEN (0x12011003) pour la PS4 Pro.

La compilation Full LTO améliore les performances générales mais augmente sensiblement la mémoire nécessaire à la compilation ; prévoyez au moins 8 Go de swap sur la machine de build si vous recompilez vous-même. Les tentatives de modification du nombre de SE/SH ou du pipe config provoquent des corruptions d'affichage et ne sont pas recommandées : conservez la topologie native (9 CU/SE, 18 CU Liverpool, 36 CU Gladius).

Les liens et empreintes SHA256 sont à compléter une fois les fichiers hébergés sur l'espace free.fr (dossier /dl/bzimage/ par exemple). Pensez à publier aussi le fichier .config associé à chaque build.

Bootargs recommandés

root=/dev/sda2 rw quiet splash
amdgpu.gpu_recovery=1 amdgpu.dc=0
video=HDMI-A-1:1920x1080@60

Recompiler soi-même

git clone <dépôt-kheops-fullto>
cd kheops-fullto
make CC=clang LD=ld.lld ARCH=x86 \
     KCFLAGS="-march=btver2 -mtune=btver2 -flto=full" \
     -j$(nproc) bzImage
