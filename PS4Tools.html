PS4TOOLS : l'outil tout-en-un pour PS4 Linux

PS4TOOLS est une interface graphique GTK/YAD, crée pour faciliter toutes les tâches, Linux PS4. Accessible pour les débutants, de nombreux tutoriaux sont présent sur ce site. (Exemple de tutoriel SSD/USB All In One)

Fonctionnalités

  • Interface multi-onglets
  • Gestionnaire de téléchargement avec scraping en direct du site
  • Création de SSD/USB bootable en quelques clics
  • Configuration persistante entre les lancements
  • Support Mega.nz intégré
  • Journalisation centralisée (logs)
  • Onglet communautaire Payload-launcher
  • Support de compilation mesa pour PS4
  • Support de compilation des kernels
  • Créer vos.img et tar.gz de vos distributions
  • Bien d'autres, options vous attendent...

Installation

Télécharger le script :

wget "http://hostps4.free.fr/Ps4-Linux-Warez/scripts/ps4-tools-en-final7.sh"
chmod +x ps4-tools-en-final7.sh
./ps4-tools-en-final7.sh

Vous devez installer yad , PS4TOOLS, vous indiqueras toutes les dépendances manquantes, a chaque étapes il vous indique ce qu'il faut faire.

Déplacez vous dans la section tutoriels, de ce site. Il vous suffit de quelques minutes pour prendre en main PS4TOOLS.

Je suis sur divers discord, si vous rencontrez des problèmes. Triki1
